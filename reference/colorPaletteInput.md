# An modified version of `shinyWidgets::pickerInput`

An modified version of
[`shinyWidgets::pickerInput`](https://dreamrs.github.io/shinyWidgets/reference/pickerInput.html)

## Usage

``` r
colorPaletteInput(
  inputId,
  label = NULL,
  n = 5,
  filters = "none",
  series = c("tableau", "brewer", "cols4all", "matplotlib"),
  type = c("cat", "seq"),
  range = NA,
  continuous = FALSE,
  reverse = FALSE,
  ...
)
```

# Look up river mileage for a table of points

Look up river mileage for a table of points

## Usage

``` r
xy2station(
  tbl,
  crsid = 25832,
  stationSearchUrl = "https://via.bund.de/wsv/bwastr-locator/rest/stationierung/query"
)
```

## Arguments

- tbl:

  Table of x, y coordinates

- crsid:

  CRS-ID

- stationSearchUrl:

  URLs to lookup service of WSV

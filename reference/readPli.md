# Read .pli data to sf_linestring

This function can read file in Deltares-polyline format with or without
Z values and convert it to a sf LINESTRING.

## Usage

``` r
readPli(path, crs = sf::NA_crs_)
```

## Arguments

- path:

  Path to the .pli file (only x, y)

- crs:

  Coordinate system of the polyline, eg. crs = "EPSG:25833"

## Value

sf_linestring

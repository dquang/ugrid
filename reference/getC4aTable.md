# Prepare a simple table of colors based on `cols4all::c4a_table`

Prepare a simple table of colors based on
[`cols4all::c4a_table`](https://cols4all.github.io/reference/c4a_gui.html)

## Usage

``` r
getC4aTable(
  type = c("all", "cat", "seq", "div", "cyc"),
  n = NULL,
  m = NULL,
  sort = "name",
  series = "all",
  filters = "none",
  range = NA
)
```

# Prepare data for downloading.

This function is exported for using in future calls

``` r
prepareData4Download(
  mdta1,
  mdta2 = NULL,
  iline1 = NULL,
  iline2 = NULL,
  fids = NULL,
  pid = NULL,
  lgT1 = NULL,
  lgT2 = NULL,
```

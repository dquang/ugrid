# A shiny app for observing ugrid data stored in NetCDF files

A shiny app for observing ugrid data stored in NetCDF files

## Usage

``` r
ugridApp(options = list(launch.browser = TRUE))
```

## Arguments

- options:

  list of options for
  [`shiny::shinyApp`](https://rdrr.io/pkg/shiny/man/shinyApp.html)
